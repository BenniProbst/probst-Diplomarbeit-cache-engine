ZWECK
   Vollstaendige Cross-Paper-Aufstellung aller Allokator-Bausteine pro
   konzeptionelle Achse aus den 23 Papern (A01-A23). Jeder Baustein:
   - Erweitert std::allocator<T> typsicher (REV-7 §3.1 A1)
   - Bietet std::pmr::memory_resource-Konformanz (REV-7 §3.1 A2)
   - Default Concurrency: Single-Writer-Multi-Reader via std::shared_mutex
   - Optional: Cache-Page-Aware Multi-Writer via std::scoped_lock
   - Pflicht-Tests: Container-Matrix x Threading x Concurrency-Sicherheit

NOTATION
   ID            Eindeutige Bausteine-ID (= Flag-Position fuer
                 PermutationFlags der CacheEngine)
   QUELLE        A-ID des Originalpapers
   CLUSTER       AC1-AC5 (Foundation/ModernProd/NUMA/Concurrent/Standard)
   ORIG-COMP.    Original-Compiler-/Sprach-Anforderung
   CONCEPT       C++23 Concept (in cache_engine/include/cache_engine/allocators/concepts/)
   ABHAENGIG     Andere Bausteine, von denen dieser abhaengt
   IMPL-PFAD     Pfad zum Code (siehe § Implementierungs-Pfade am Ende)

AA1 — FREE-LIST-TOPOLOGIE
================================================================================

ID: ALLOC_FREELIST_FLAT_LIFO
   QUELLE        A20 dlmalloc (Doug Lea)
   CLUSTER       AC5 Standard + Optimizing
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Doppelt verkettete Listen pro Smallbin (32 lists), Trie pro
                 Treebin fuer >256 Byte. Wilderness top chunk preserved.
   ABHAENGIG     ALLOC_SIZECLASS_DLMALLOC

ID: ALLOC_FREELIST_SUPERBLOCK_HOARD
   QUELLE        A01 Hoard (Berger ASPLOS 2000)
   CLUSTER       AC1 Foundation
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Innerhalb Superblock: LIFO Free-List (Cache-Lokalitaet).
                 Pro Heap: doubly-linked List of Superblocks per Fullness-Group.
                 Move-to-Front-Heuristic.

ID: ALLOC_FREELIST_SLAB_BUFCTL
   QUELLE        A02 Bonwick Slab (USENIX 1994)
   CLUSTER       AC1 Foundation
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Pro-Cache: doubly-linked Slab-List (empty/partial/complete
                 sortiert). Pro-Slab: einfache bufctl-Liste (in-buffer linkage).

ID: ALLOC_FREELIST_LOCKFREE_ANCHOR
   QUELLE        A03 Michael Lock-Free (PLDI 2004)
   CLUSTER       AC1 Foundation
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Per-Superblock LIFO via Anchor.avail (atomic 64-bit).
                 Pro Sizeclass: lock-free FIFO Partial-List.

ID: ALLOC_FREELIST_PAGE_SHARDED_3LIST
   QUELLE        A04 mimalloc (Leijen MSR 2019)
   CLUSTER       AC2 Modern Production
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Pro mimalloc-page (64 KiB) drei Free-Lists:
                 (1) free (allocation), (2) local_free (slow path),
                 (3) thread_free (atomic foreign frees).

ID: ALLOC_FREELIST_BITMAP_RUN_JEMALLOC
   QUELLE        A05 jemalloc (Evans BSDCan 2006)
   CLUSTER       AC2 Modern Production
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Bitmap-basiert pro Run; Red-Black-Tree pro Arena fuer
                 freie Runs/Chunks.

ID: ALLOC_FREELIST_PERTHREAD_TCMALLOC
   QUELLE        A06 tcmalloc (Google 2009/2024)
   CLUSTER       AC2 Modern Production
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Pro size-class single-linked Object-Liste (per-thread cache);
                 Span = 2-byte indexed Array (Cache-effizient).
                 Modern: Per-CPU Cache 256 KiB Slab per CPU.

ID: ALLOC_FREELIST_BUMPHYBRID_SNMALLOC
   QUELLE        A07 snmalloc (Lietar et al. ISMM 2019)
   CLUSTER       AC2 Modern Production
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Hybrid Bump-Pointer + Lazy Free-List per Slab; Per-Thread
                 Pending-Bucket-Array (2^k=64 Buckets) fuer batched message-passing.

ID: ALLOC_FREELIST_GLOBAL_LOCKFREE_LIFO_SCALLOC
   QUELLE        A08 scalloc (Aigner et al. OOPSLA 2015)
   CLUSTER       AC2 Modern Production
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Per-Span object freelist (LIFO); Pro Size-Class globaler
                 Span-Pool als lock-free LIFO (Treiber-stack-style).

ID: ALLOC_FREELIST_NUMA_PERNODE
   QUELLE        A09 NUMAlloc (Yang et al. ISMM 2023)
   CLUSTER       AC3 NUMA + Hardware
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Pro NUMA-Node eigene Free-Lists; Per-Thread Cache mit
                 NUMA-Origin-Tag.

ID: ALLOC_FREELIST_RPMALLOC
   QUELLE        A10 rpmalloc (Jansson Public Domain)
   CLUSTER       AC3 NUMA + Hardware
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Per-Thread Cache + Global Cache; aehnlich tcmalloc-style
                 aber single-file 2000 LOC C-Library.

ID: ALLOC_FREELIST_LOCKFREE_THREADCACHE_LRMALLOC
   QUELLE        A11 LRMalloc (Leite/Rocha VECPAR 2018)
   CLUSTER       AC4 Concurrent + Formal
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Per-Thread Cache (modern Hot-Path) + Per-Procheap
                 Active+Partial (von Michael 2004 geerbt).

ID: ALLOC_FREELIST_CACHESET_DIRECTED_CAMA
   QUELLE        A12 CAMA (Herter et al. ECRTS 2011)
   CLUSTER       AC3 NUMA + Hardware
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Pro Cache-Set eigene Free-Liste; User waehlt Set bei alloc

ID: ALLOC_FREELIST_BITMAP_AVL_STARMALLOC
   QUELLE        A13 StarMalloc (Reitz/Fromherz/Protzenko OOPSLA 2024)
   CLUSTER       AC4 Concurrent + Formal
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Bitmap pro Slab + AVL-Tree fuer Slab-Metadata + FIFO Queue

ID: ALLOC_FREELIST_LIFETIME_AWARE_L8_TCMALLOC2024
   QUELLE        A14 ASPLOS 2024 TCMalloc Characterization (Zhou et al.)
   CLUSTER       AC3 NUMA + Hardware
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  L=8 Span-Lists in Central FreeList differenziert nach

ID: ALLOC_FREELIST_LOCAL_SHARED_HMALLOC
   QUELLE        A15 HMalloc (Li/Yao 2019)
   CLUSTER       AC4 Concurrent + Formal
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Strikte Trennung Local (per-thread, coalescence-free) und

ID: ALLOC_FREELIST_PIM_CORE_LOCAL
   QUELLE        A16 PIM-malloc (Lee et al. HPCA-32 2026)
   CLUSTER       AC3 NUMA + Hardware
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Per-PIM-Core eigene Free-Lists in PIM-Memory;

ID: ALLOC_FREELIST_BUDDY_BITMAP
   QUELLE        A19 Buddy (Knuth/Knowlton 1965/1968)

ID: ALLOC_FREELIST_PTMALLOC_TCACHE_FASTBIN
   QUELLE        A21 ptmalloc2 / glibc malloc (Wolfram Gloger)
   CLUSTER       AC5 Standard + Optimizing
   CONCEPT       FreeListTopology<T>
   BESCHREIBUNG  Hierarchie: tcache (per-thread, glibc 2.26+) → fastbin

ID: ALLOC_FREELIST_VMEM_POW2_RB
   QUELLE        A23 Vmem (Bonwick/Adams USENIX ATC 2001)
   CLUSTER       AC1 Foundation
   CONCEPT       FreeListTopology<T>

ID: ALLOC_FREELIST_MAGAZINE_STACK_VMEM
   QUELLE        A23 Magazines (Bonwick/Adams USENIX ATC 2001)
   CLUSTER       AC1 Foundation
   CONCEPT       FreeListTopology<T>

ID: ALLOC_FREELIST_SINGLE_PAGE_EXGEN

AA2 — SIZE-CLASS-SCHEMA
================================================================================

ID: ALLOC_SIZECLASS_POW2
   QUELLE        A19 Buddy (Knuth/Knowlton)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  Strikte Power-of-2-Klassen, max 50% internal frag.

ID: ALLOC_SIZECLASS_HOARD_POWB
   QUELLE        A01 Hoard (Berger 2000)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  Power-of-b mit b > 1 (Default b=1.2) → internal frag bound by b.

ID: ALLOC_SIZECLASS_OBJECT_CACHE_SLAB
   QUELLE        A02 Bonwick Slab (1994)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  Object-Cache pro Typ (vom Client erstellt), default
                 ~30 Caches in 8B-9K range mit 10-20% increments.

ID: ALLOC_SIZECLASS_TIERED_JEMALLOC
   QUELLE        A05 jemalloc (Evans 2006)
   CLUSTER       AC2 Modern Production
   BESCHREIBUNG  4 Tiers: Tiny (2-16B pow2), Quantum-spaced (16-496B 16B-
                 quantum), Sub-page (512-2048B pow2), Large (page-multiples),
                 Huge (chunk-multiples).

ID: ALLOC_SIZECLASS_TCMALLOC_88
   QUELLE        A06 tcmalloc (Google)
   CLUSTER       AC2 Modern Production
   BESCHREIBUNG  ~80-90 carefully chosen Klassen; max ~12.5% internal frag;
                 8/16-Byte alignment.

ID: ALLOC_SIZECLASS_PAGE_DIRECT_MIMALLOC
   QUELLE        A04 mimalloc (Leijen 2019)
   CLUSTER       AC2 Modern Production
   BESCHREIBUNG  pages_direct[1024]: direct array fuer Objects <1 KiB;
                 pages[]: lists pro size class darueber.
                 Max internal frag 1/6 = 16.7%.

ID: ALLOC_SIZECLASS_VIRTUAL_SPAN_SCALLOC
   QUELLE        A08 scalloc (Aigner et al. 2015)
   CLUSTER       AC2 Modern Production
   BESCHREIBUNG  Power-of-2 Span-Sizes (4 KiB - 1 MiB), uniforme Behandlung
                 Small+Medium+Large.

ID: ALLOC_SIZECLASS_SNMALLOC_3TIER
   QUELLE        A07 snmalloc (Lietar 2019)
   CLUSTER       AC2 Modern Production
   BESCHREIBUNG  Small (<64 KiB) / Medium (64 KiB-16 MiB) / Large (≥16 MiB).

ID: ALLOC_SIZECLASS_FINEGRAINED_8B_EXGEN
   QUELLE        A18 Exgen-Malloc (Li/John/Yadwadkar 2025)
   CLUSTER       AC5 Standard + Optimizing
   BESCHREIBUNG  8-byte fine-grained steps statt power-of-2 → reduce internal frag.

ID: ALLOC_SIZECLASS_DLMALLOC
   QUELLE        A20 dlmalloc (Doug Lea)
   CLUSTER       AC5 Standard + Optimizing
   BESCHREIBUNG  32 Smallbins (8-byte steps bis 256B) + Trie fuer Large +
                 mmap-Threshold (~128 KiB) separation.

ID: ALLOC_SIZECLASS_PTMALLOC_HIERARCHY
   QUELLE        A21 ptmalloc2 / glibc
   CLUSTER       AC5 Standard + Optimizing
   BESCHREIBUNG  tcache: 64 bins (24-1032B, 16B steps); fastbin: 10 (≤160B);
                 smallbin: 62 fixed; largebin: 32 ranged.

ID: ALLOC_SIZECLASS_PMR_POOL_OPTIONS
   QUELLE        A22 N3916 PMR (C++17 std::pmr)
   CLUSTER       AC5 Standard + Optimizing
   BESCHREIBUNG  pool_options.max_blocks_per_chunk +
                 largest_required_pool_block konfigurierbar.

   QUELLE        A20 dlmalloc Treebin

   BESCHREIBUNG  Best-fit via Trie/Tree-Suche fuer Large-Requests.

   QUELLE        A01 Hoard (Berger 2000)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  Always allocate from "fullest" superblock (move-to-front

   QUELLE        A03 Michael (2004), A11 LRMalloc
   CLUSTER       AC1+AC4
   BESCHREIBUNG  3-Pfad-Hierarchie: MallocFromActive (Hot) →

   QUELLE        A07 snmalloc (Lietar 2019)
   CLUSTER       AC2 Modern Production

   QUELLE        A23 Vmem (Bonwick/Adams 2001)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  Power-of-2 Freelist + Instant-Fit (take first in

   QUELLE        A23 Vmem (Bonwick/Adams 2001)
   CLUSTER       AC1 Foundation
   BESCHREIBUNG  VM_BESTFIT-Option: search freelists fuer best-fit (langsamer

ID: ALLOC_POLICY_NEXT_FIT_VMEM
   QUELLE        A23 Vmem (Bonwick/Adams 2001)

   BESCHREIBUNG  VM_NEXTFIT-Option: cyclic search starting at last-allocated.

ID: ALLOC_POLICY_NUMA_ORIGIN_AWARE
   QUELLE        A09 NUMAlloc (Liu/Berger 2023)
   CLUSTER       AC3 NUMA + Hardware
   BESCHREIBUNG  Origin-Aware: Re-Use bleibt auf gleichem NUMA-Node.

ID: ALLOC_POLICY_CACHE_SET_DIRECTED_CAMA
   QUELLE        A12 CAMA (Herter et al. 2011)
   CLUSTER       AC3 NUMA + Hardware
   BESCHREIBUNG  User-controlled placement: addr & cache_index_mask == set.

ID: ALLOC_POLICY_TCACHE_FAST_FALLTHROUGH
   QUELLE        A21 ptmalloc2 (glibc), A06 tcmalloc, A05 jemalloc
   CLUSTER       AC2+AC5
   BESCHREIBUNG  tcache → fastbin → smallbin → unsorted → largebin → top

ID: ALLOC_POLICY_SPAN_PRIORITIZATION_LIFETIME
   QUELLE        A14 ASPLOS 2024 TCMalloc Optimization 3

ID: ALLOC_POLICY_PIM_METADATA_PIM_EXECUTED

   CLUSTER       AC3 NUMA + Hardware

                    → Linux-Production-Optimum

  [PRT-ART-Pool]   = AA1 SUPERBLOCK + AA2 OBJECT_CACHE_SLAB

                   + AA5 FULLEST_SUPERBLOCK + AA6 REFCOUNT_SLAB

PRT-ART NUTZUNG (Pool A/B/C/D/R/V) — Mapping zu Allokator-Achsen
================================================================================

PRT-ART definiert 4+2 Pools (REV 6 §5.17 + §5.21):

Pool A (256B Slabs fuer Suchtyp A Array[256]):
  AA1 SLAB_BUFCTL + AA2 OBJECT_CACHE + AA7 SLAB_COLORING

Pool B (64KB Slabs fuer Suchtyp B Array[65535]):
  AA1 SUPERBLOCK + AA2 OBJECT_CACHE + AA7 HUGEPAGE_FILLER (option)

Pool C (4KB+ variable fuer Suchtyp C Vector<u8,u8>):
  AA1 SLAB_BUFCTL + AA2 PAGE_DIRECT + AA5 BUMP_POINTER_THEN_FREELIST

Pool D (4KB+ variable fuer Suchtyp D Vector<u16,u16>):
  AA1 SLAB_BUFCTL + AA2 PAGE_DIRECT + AA5 BUMP_POINTER_THEN_FREELIST

Pool R (Redirect-Knoten 64B Cache-Line):
  AA1 SLAB_BUFCTL + AA2 OBJECT_CACHE + AA7 SLAB_COLORING

Pool V-static (Values mit statischer Groesse):
  AA1 SLAB_BUFCTL + AA2 OBJECT_CACHE + AA5 BUMP_POINTER

Pool V-dynamic (Values mit dynamischer Groesse + Signaling-Bits):
  AA1 PAGE_SHARDED_3LIST + AA2 FINEGRAINED_8B + AA5 BUMP_POINTER_THEN_FREELIST
