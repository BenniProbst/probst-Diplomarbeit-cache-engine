ZENTRALES ERGEBNIS DIESER MATRIX
================================================================================

PRT-ART HAUPTBEITRAG (basierend auf 33-Paper-Lektuere):

  Was die Literatur ALLES bietet:
    - Adaptive Knotentypen pro Datenstruktur (P01 ART, P02 HOT, P05 START, P20 BTreesBack)
    - Cache-aware Layouts (P11 CSS, P12 CSB+, P13 Hankins, P14 Samuel)
    - Probability-basierte Layout-Optimierung (P16 Bender, P28 Kuehn)
    - Online-Relocation (P18 Saikkonen 2008)
    - Prefetching-Familie (P21-P27)
    - Plattform-Kalibrierung (P14 Samuel Configuration Experiment)
    - Cost-Model-basierte Optimierung (P05 START)
    - Synchronization (P08 ART OLC, P29 RCU, P30 Hazard Pointers)
    - Succinct Encoding (P09 Jacobson, P10 SuRF, P04 CoCo-trie)

  Was die Literatur NICHT bietet:
    1. Eine **getrennte Cache-Engine als Meta-Ebene** ueber trie-basierter Suche
       → ALLE Such-Algorithmen integrieren Layout-Wahl IN die Datenstruktur
    2. **Online (runtime-adaptive) Re-Layouting** fuer dynamische Indizes
       → P28 Kuehn DAMON 2023 schliesst das EXPLIZIT aus
    3. Eine **gemeinsame Wahl** von Seitentyp + Layout + Inline + Prefetch + Allocator
       → Alle Quellen optimieren EIN Aspekt, nicht alle gemeinsam
    4. **Plattform-bewusste online Adaption** ueber ISA-Pfade
       → START (P05) macht offline; PRT-ART macht online

  Das ist die **vier-fache Forschungsluecke** von PRT-ART, jetzt durch
  die Tieflektuere aller 33 Paper als nicht-trivial bestaetigt.
