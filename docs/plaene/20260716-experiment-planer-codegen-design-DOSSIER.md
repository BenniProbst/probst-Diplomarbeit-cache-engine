## (B) Design (benannte GoF-Muster)
**Interpreter** (XML→`ExperimentPlan` = geordnete `PhaseStep`-Liste: je Phase Systemachsen-Kombis × Tier-Binary-Selektion × Lastprofile × Mess-Modus) + **EIN `ExperimentPlanDirector::construct(IPlanBuilder&)`** + **ZWEI ConcreteBuilder** `CiYamlBuilder` / `CMakeGraphBuilder` aus DEMSELBEN Walk → **Synchronie strukturell garantiert** (nicht zwei parallel gepflegte Emitter). **Template Method** je `PhaseStep`: `resolve_selection`(CoR `selection_filter_chain`) → `emit_build`(BuildOrchestrator, Systemachsen-Kombi) → `emit_measure`(Debug=Thread-Pool / Mess=1-Thread+Gattungs-Threading) → `emit_serialize`(flacher Systemachsen-Ordner + tiefer Tier-Baum + dynamik-CSV) → `emit_copy`(build→ziel atomar + Index-Manifest). CMakeGraphBuilder=`add_custom_command`+`DEPENDS`; CiYamlBuilder=CI-Job+`needs:` — dieselbe Topologie, zwei Syntaxen.
- **CI-YAML:** dynamische Child-Pipeline, `measure:*` ersetzt durch 1 generierenden Job + `trigger:include:artifact:`; je PhaseStep `build:<phase>:<combo>`→`measure:<phase>:<combo>`(`needs:`); Systemachsen-Kombis als `parallel:matrix` ODER Downstream-`trigger` je Runner-Tag (`[baremetal,amd]`/`[intel]`/`[arm64]`, wie CE `:98-133`).
- **cmake:** `generated/experiment_plan.cmake` je PhaseStep `comdare_exp_<phase>_{build,measure,serialize,copy}`-Targets (`add_dependencies`), Dach-Target `comdare_experiment_run`.
- **Debug/Mess-Schalter:** neues `<measurement mode="debug|mess" threads="N"/>`; Bau immer parallel; Mess: Debug=Pool über (Binary×Setting), Mess=1-Thread + `thread_count`-Konsum (#221) — durchgereicht an `measure_under_setting` (`cache_engine_builder_iterator.hpp:777`, `loop.run :836`).
- **"failed"-Sichtbarkeit:** try/catch um `run_*_perm` (`:790-794`); bei Fehler CSV-Zelle `"failed"` (statt null) + `<binary_id>.error.log` neben `result.csv`, Harness `continue` (Stamp NICHT gesetzt). Additiv zum `two_phase_valid`-Pfad.
- Planer/Codegen = strikt **Pre-Build/Configure-Zeit**; Hot-Path bleibt compile-time-only (`PhaseStrategyFor<S>`); kein Python.

## (C) Increments + Forks
**Increments:** I1 Planer-Binary-Skelett (`--dump-plan`, golden-neutral, Contract-Test) → I2 `CMakeGraphBuilder`+2-Pass (opt-in `-DCOMDARE_EXPERIMENT_XML=`) → I3 `CiYamlBuilder`+Child-Pipeline (INERT-by-default) → I4 Debug/Mess-Schalter (#221) + "failed"-Zelle → I5 Serialisierungs-Emitter (flacher Ordner + build→ziel-Copy + Index-Manifest).
**Forks (Morgen):** **F1** CI-YAML-Erzeugung Configure-Zeit (CMake `execute_process`) vs. **(b, Empf.)** Planer-Laufzeit-Job + `trigger:include:artifact` (GitLab-idiomatisch). **F2** Systemachsen-Fan-out `parallel:matrix` vs. Downstream-`trigger` je Runner-Tag. **F3** Verhältnis zu `COMDARE_PERMUTATION_PROFILE`: (a) Planer leitet es aus `metadata.mode` ab (Single-Source, mittelfristig) vs. **(b, sicherer erster Schritt)** unabhängig. **F4** Index-Manifest-Format (JSON/XML/CSV, passend zum Reihe-C-Konsumenten).
