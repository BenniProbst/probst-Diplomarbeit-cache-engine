## §2 V18.1 Multi-Path-Lookup-Strategie

`CodegenEngine::generate_module_from_profile` sucht in 2 Pfaden:

**Prioritaet 1 (SOTA):**
```
opts_.comdare_root/cache_engine/builder/codegen/templates/<id>_body.hpp.template
```

**Prioritaet 2 (Pruefling, opt-in via prt_art_root):**
```
opts_.prt_art_root/prt_art/codegen/templates/<id>_body.hpp.template
```

Bei `prt_art_root`-Empty: nur SOTA-Pfad (V17.1-Verhalten, abwaerts-kompatibel).

`ExperimentDriverOptions::prt_art_root` neu hinzugefuegt + Phase 2
propagiert es an `CodegenOptions::prt_art_root`.
