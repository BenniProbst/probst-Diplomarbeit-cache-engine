- `merge(other)` — alle Eintraege aus `other` ruebernehmen wenn Key nicht existiert
- `extract(key)` — Eintrag entfernen + zurueckgeben (analog std::map::extract)
- Cross-Engine-Lock via `std::scoped_lock{rw_lock_, other.rw_lock_}` (deadlock-vermeidend)
