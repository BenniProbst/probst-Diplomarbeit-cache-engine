## §4 V14.3 — CI Test-Discovery-Workaround

Alle 6 CI-Konfigurationen (3 GitLab + 3 GitHub Actions) nutzen jetzt
**direkte Test-Binary-Ausfuehrung** statt `ctest`/`gtest_discover_tests`:

```yaml
# vorher:
- ctest --test-dir build --output-on-failure

# nachher (V14.3):
- ./build/tests/unit/test_prt_art_identity
```

Vorteile:
- Umgeht MSB3073 (gtest_discover_tests bei MSVC discovery-time)
- Plattform-uniform (Linux + Windows identisch)
- Klarere Fehler-Logs (direkte gtest-Ausgabe statt CMake-Wrapping)
