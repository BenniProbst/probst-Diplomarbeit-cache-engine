## §3 Designentscheidungen V11

### §3.1 V11.7 CI-Strategie (User-Direktive)
- **Primaer GitLab** (`.gitlab-ci.yml` in Repo-Root)
- **Synchron GitHub Actions** (`.github/workflows/ci.yml`)
- Identische Jobs in beiden:
  - `configure-default` — cmake configure ohne EXPERIMENT_MODE
  - `configure-experiment` — cmake configure mit -DCOMDARE_EXPERIMENT_MODE=ON
  - `test` — ctest (auf Linux, MSVC-Tests sind User-lokal)
- Matrix: ubuntu-latest + windows-latest fuer GitHub Actions
- GitLab Runner: docker:debian + Windows-Runner (falls verfuegbar)
- Submodules: `submodules: recursive` in beiden

### §3.2 V11.1 Komponenten-API-Erweiterung
- `PrtArtComponents` Mitglieder werden `public` exposed via Friend-Declaration
  oder direkter Public-Sicht
- Neue Methoden:
  - `DensityTracker::note_observation(double sample)`
  - `PathOrientedPrefetch::note_hot_path_bytes(byte const*, std::size_t)`
  - `PrtArtHypothesisMetrics::adapt_locality(double locality)`
- Adapter aktiviert die echten Bodies statt TODO-Stubs

### §3.3 V11.2 Workload-Routing
- Pro Profil: ableitbar aus `traversal`-Achse (z.B. RANGE_SCAN → YCSB-E,
  HOT_PATH → YCSB-A, STANDARD → YCSB-C)
- WorkloadOptions wird pro Profil-Modul gesetzt vor `run_workload`-Aufruf

### §3.4 V11.3 Messreihen-XML → ExperimentDriverOptions
```cpp
for (auto const& spec : external_specs) {
    cb::ExperimentDriverOptions opts = base_opts;
    opts.messreihen_mode = (spec.mode == "full") 
        ? cb::ExperimentDriverOptions::MessreihenMode::Full
        : cb::ExperimentDriverOptions::MessreihenMode::Defined;
    opts.sota_profile_filter = spec.sota_profiles;
    cb::ExperimentDriver{opts}.run_pipeline_full(...);
}
```

### §3.5 V11.4 Variant-Body-Pattern
```cpp
struct PageStandardHeap {
    static constexpr char tag[]         = "STANDARD_HEAP";
    static constexpr char description[] = "Default heap-allocated page (no special layout)";
    static constexpr char paper_ref[]   = "(none)";
};
struct PageDenseByteArt256 {
    static constexpr char tag[]         = "DENSEBYTE_ART256";
    static constexpr char description[] = "ART Node256 dense byte page";
    static constexpr char paper_ref[]   = "P01";
};
```
Compile-Time-Reflection bleibt ohne dynamic dispatch.
