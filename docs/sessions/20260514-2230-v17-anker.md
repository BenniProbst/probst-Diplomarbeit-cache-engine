## §2 V17.1 Designentscheidung

`CodegenEngine::generate_module_from_profile` wird um Template-Lookup
erweitert:

```cpp
auto template_path = opts_.comdare_root /
    "cache_engine/builder/codegen/templates" /
    (profile.id + "_body.hpp.template");
bool const has_template = std::filesystem::exists(template_path);
```

Bei `has_template == true`:
- generierter `.cpp` enthaelt `#include` des Templates statt Skelett-Body
- ABI-Glue ruft die Template-Body-Klasse auf (Pattern aus V16.3 README)

Bei `has_template == false`: Skelett-Body wie bisher (V9.3-Verhalten).

Damit ist der Wechsel **nicht-disruptiv**: bestehender Codegen
funktioniert weiter, neue Templates werden nur dann verwendet, wenn
sie vorhanden sind.
