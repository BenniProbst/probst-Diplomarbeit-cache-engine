## (D) ARCHITEKTUR-KERNE dieses Segments

1. **Achsen sind der Ersetzungs-Mechanismus, nicht eine Konfigurationsliste.** Owner: *„Achsen sollen die Aufgaben ihrer äquivalenten Code-Stellen in ALLEN anderen Achsen ersetzen, sodass über die Ausführungs-Art und Konfiguration einer Achse deren EFFEKT GLOBAL sichtbar wird."*
2. Daraus die **generalisierte Schnitt-Regel**: *„ALLE Achseneigenschaften … NUR noch über die Achsen … ausser die Implementierung eines Genus ruft als erste Instanzen fremde Achsen zum ersten Mal auf."*
3. **Regressions-Definition:** *„Es ist eine Regression, wenn ein Organ-Algorithmus keiner Achse zugeordnet ist und durch das metaprogrammierte Achsen-Interface angesprochen wird."*
4. **Zwei-Ebenen-Modell final:** *„Das Genus erbt von der gemeinsamen Gattung. Ein Set erbt bezüglich des Interface von Container (Container ist … die Hauptgattung und SearchAlgorithm ist ein Genus unter der Gattung ‚Map')."* Gattungs-Kern = Schnittmenge; Graph = Stub.
5. *„Gattung und Genus sind gestaffelte Interface Definitionen, die per abstract factory (metaprogrammiert zur compile time) implementiert werden. Die Achsen sind die Bausteine, die unter der Haupt-Implementierung der Genus … cross Gattung und cross Genus und cross zwischen den Achsen gebaut werden."*
6. **Rekursion:** metaprogrammatisch unbegrenzt erlaubt, zur Laufzeit imperativ — *„sodass keine loop entsteht, die zum stack overflow führt."* Topologie SA → Achsen → Achsen → Container-Gattung → deren Achsen.
7. **Stufen-Doktrin (Owner-abgenommen):** Mess DREISTUFIG dehnbar Planer(RT) → CEB(CT) → [Hybrid(CT)] → Tier(CT) · System ZWEISTUFIG dehnbar CEB(RT) → [Hybrid(CT)] → Tier(CT) · Organ ZWEISTUFIG, hybrid-unberührt. **Stufe 1 immer RT-Freigabe, Folgestufen CT-Einbau.**
8. *„Die Organ-Achsen … berühren die Hybriden NICHT direkt, da die Hybriden ein **factory pattern - facade - Adapter** sind"* — Hybrid trägt Mess- und System-Stempel, **keine Organ-Identität**.
9. **Legenden-Vertrag (§56):** `ceb:build:[a,b,c]` · `tier:build:[d,e,f][g,h,i]` (die Mess-Achse **ist** die CEB) · `measure:[a,b,c][d,e,f][g,h,i]`.
10. **Zwei-Layer-Trennung auch in der CEB-LAUFZEIT:** `[d,e,f]` Hardware-Layer, `[g,h,i]` Anwendungs-Layer — äußere System-Schleife, inneres Organ-Fenster, **nie gemischt**.
11. **Meta-Meta zweischichtig:** Manager permutiert **Existenz (an/aus)** UND Werte — Achsen-ZAHL wächst dynamisch je Maschine, Existenz-Wahl bleibt compile-time.
12. **Stempel-Grammatik:** Klammer-Tiefe = Meta-Meta-Ebene (offene Rekursion), Punkte vor `@` = hierarchische Namen; `X.Y.Z` je Algorithmus, `e` = experimentell (nur Prüfling), Bits im `reserved` tragen experimental/HW-Flag/Ebene.
13. **Replay-Schlüssel sind schichtweise verschieden:** CEB ← Mess, Tier ← System ALLEIN, Messwerte ← System+Organ + Hardware-Identität. **Binary-Sharing stempel-gekeyt, Messwert-Replay hardware-gekeyt.**
14. **Lagerhaltung ist ein Vertrag, kein Cache:** versioniertes gelocktes XML · zwei Bestände als Factory Pattern · 4096er-Batches, Claim = **Versprechen** · ETA = Σt/N mit Untergrenze max(t) · Takeover ETA+50 % · **Job-Anzahl O(Maschinen), nie O(Binaries)**.
15. **Batch = bauen → am Prüfdock testen → erst dann messen.** Owner: *„ALLE Achsen-Algorithmen UND Tier-Binary Interfaces müssen umfassend mit deep research tests nach dem compile belegt werden."*
16. **Vier Modi:** Debug → Messung → Release (**Wallclock-Beweis der schnellsten Binary**) → Compare. **EIN Modus je Call, per XML.** `+bt=` ist der Compile-Typ, nie der Modus.
17. *„RELEASE = ZIEL DES GESAMTPROJEKTS"* — Messwerte → Break-Even-Heuristik (Spline-Schnittpunkte je Achse) → Hybrid-Tier-Binaries → finale Binary, bewiesen gegen beste-Debug und schlechteste XML-Variante.
18. **Ein Kanal, eine XML:** *„Es gibt eine XML als Quelle für den gesamten Prozess und einen Kanal der es baut, Punkt."* Keine Skripte außer CMake; je Achsen-Typ genau ein Konfigurations-Ort.
19. **Zielbild Planer:** eigene Binary mit Shell-CLI, **anspruchslos**, **taktet selbst**, **liest zurück** (`status` über Bestandslog-XML).
20. **Kein Abbruch:** *„Pipelines müssen hart grün durchlaufen, da wird nichts unterbrochen, sonst ist nachher die Lagerhaltung beschädigt."*
