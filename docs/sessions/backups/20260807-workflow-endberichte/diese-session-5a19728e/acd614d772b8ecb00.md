## Frage 3 — Break-even je Ebene: ein Schnittkurven-Satz pro Erhebungs-Ebene oder ein gemeinsamer?

**DOKUMENTIERTE ANTWORT: PRO EBENE.** Break-even ist keine gemeinsame vierte Stufe über alle Ebenen, sondern eine Operation, die auf jeder Ebene anwendbar ist — gekreuzt werden Kurven **derselben** Ebene.

`PLAN-BREAK:334-339` (Plan-Aussage):
> „Horizontal: innerhalb JEDER Ebene entstehen Kurven über den Parameter x → und überall dort, wo zwei Kurven **derselben Ebene** sich kreuzen, liegt ein BREAK-EVEN-PUNKT. … Break-Even ist **kein vierter Schritt nach den drei Ebenen**, sondern die **Operation, die auf jeder Ebene anwendbar ist**. Der Plan hat sie heute nur auf einer Ebene ausformuliert (Achsen-intern, Abschnitt 2.4)."

Stützend: Konsistenz-Invariante „Summe(E1) ≤ E2 ≤ E3 … Coverage gegen den **je-Ebene** kommensurablen Nenner" (`PLAN-BREAK:314`); IST: `break_even.hpp:3` schneidet nur Splines **derselben** Organ-Achse (`DOSSIER:279`).

Owner-Verbatim-Unterbau (`ROH:7675`; gleichlautend `LEDGER:4584-4592`, Tabelle `LEDGER:4594-4598`) definiert break-even und die drei Ebenen Micro / Macro-timed / Macro-large-scope.

**Ehrliche Einordnung:** Die explizite „pro-Ebene vs. gemeinsam"-Aussage ist die **Plan-Synthese** (`PLAN-BREAK`), nicht ein separater Owner-Satz. Der Owner hat break-even + die drei Ebenen definiert, die „ein Satz je Ebene"-Formulierung aber nicht selbst als solche ausgesprochen (der Plan sagt selbst, sie sei „heute nur auf einer Ebene ausformuliert").
