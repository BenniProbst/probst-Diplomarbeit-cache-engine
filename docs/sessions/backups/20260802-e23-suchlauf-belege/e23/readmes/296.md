# comdare-measurement

Autonomous measurement and benchmarking pipeline for the comdare cache engine.

## Scope

**comdare-measurement** encapsulates the core measurement infrastructure that drives performance characterization of cache implementations across the cache-engine permutation space. It provides:

- **Deterministic Workload Generation**: YCSB-compliant workload profiles (A/B/C/D/E) with reproducible xorshift64 PRNG seeding
- **Measurement POD (ComdareMeasurementSnapshotV1)**: Unified 16+6-column schema combining pipeline metrics (cycles, L1/L2/L3 cache misses, DTLB, coherence, energy) with functional observer aggregates (search operation counts, peak occupancy)
- **Hardware Performance Counter (PMC) Abstraction**: Pluggable interface (IPmcSource) for platform-specific counter collection with honest availability signaling
- **ABI-Stable Tier Probing**: Direct measurement of loaded Anatomy modules via IObservableTier, IRollbackableTier (two-phase measurement), and IScannableTier (range-scan workloads)
- **Prüf-Dock (Test Harness) Framework**: Per-genus measurement transition points (SearchAlgorithm, Set, Sequence, Adapter, View) with conformance gating
- **Disk Checkpoint Persistence**: Memento-based state snapshots enabling rollback verification and incremental checkpoints
- **Multi-Profile Orchestration**: Host-side workload driver supporting multiple measurement profiles (fill-level sweeps, op-mix variations) per permutation binary

## Design Philosophy

The measurement pipeline operates at three integration levels:

1. **Host-Side Measurement** (WorkloadOrchestrator): Generates and executes workload profiles against loaded Anatomy modules without requiring in-DLL instrumentation. Decouples workload generation from algorithm code.

2. **ABI-Stable Interfaces**: Measurement surfaces (IObservableTier, IMeasurableWorkload, IRollbackableTier, IScannableTier) are optional sub-interfaces—newer binaries support them, older ones degrade gracefully.

3. **POD-Based Serialization**: ComdareMeasurementSnapshotV1 is a trivially-copyable struct suitable for ABI transport and CSV-based downstream analytics (LaTeX pipelines, comparison tools).

## Monolith Inventory

This module mirrors the following source inventory from `libs/cache_engine/`:

### builder/ (Measurement Core)
- `measurement_snapshot.hpp`: ComdareMeasurementSnapshotV1 POD (16 perf + 6 observer), serializers (CSV, pipeline-16)
- `pmc_source.hpp`: IPmcSource abstraction, NullPmcSource (honest PMC unavailability)
- `disk_checkpoint_memento.hpp`: DiskCheckpointStore (Memento-ABI proof, disk-resident state)
- `anatomy_module_loader/anatomy_module_loader.hpp`: dlopen/LoadLibrary with ABI-version checking, RAII lifecycle
- `anatomy_commands/tier_observe_trace_abi.hpp`: AbiTierTraceConfig, AbiFillLevelSnapshot, AbiTierObserveTrace; fill-level sweeping and Wall-Clock correlation
- `pruef_dock/pruef_dock.hpp`: IPruefDock (genus-specific measurement dock), status codes, lifecycle
- `pruef_dock/conformance_gate.hpp`: (Conformance validation before measurement)
- `workload_driver/workload_config.hpp`: WorkloadOpKind (Insert/Lookup/Erase/Clear/Scan/ReadModifyWrite), KeyDistribution (Uniform/Zipfian/Latest), WorkloadOp, WorkloadConfig
- `workload_driver/workload_generator.hpp`: Deterministic Op-sequence generation (xorshift64 PRNG, YCSB-tree profile support)
- `workload_driver/workload_orchestrator.hpp`: run_workload_profile (generic host-side driver over IObservableTier, two-phase + rollback support), WorkloadRunResult POD

### anatomy/ (Interface Layer)
- `measurable_workload.hpp`: IMeasurableWorkload (optional Stufe-B in-DLL measurement sub-interface)
- `observable_tier.hpp`: IObservableTier (Wall-Clock latency probing, observer snapshot access), ComdareTierObserverSnapshotV1
- `rollbackable_tier.hpp`: IRollbackableTier (V5-I6: two-phase measurement, save_all/rollback_all)
- `scannable_tier.hpp`: IScannableTier (V5-#49-E: range-scan support for YCSB-E profiles)
- `abi_adapter.hpp`: SearchAlgorithmAbiAdapter (bridge Anatomy concept to IAnatomyBase, includes observer/memento aggregates)

### include/cache_engine/abi/ (ABI Infrastructure)
- `anatomy_module_abi_v1_decl.hpp`: ABI-version/magic constants, extern-C factory declarations, lightweight loader header

## Building

This module provides an INTERFACE library: `comdare::measurement`

```cmake
find_package(comdare-measurement REQUIRED)
target_link_libraries(my_target PRIVATE comdare::measurement)
```

No linking step required (header-only, interfaces only).

---

## Version / ABI Stability

- **Anatomy Module ABI**: v2.2 (IDriveableTier as core; IObservableTier/IRollbackableTier/IScannableTier as optional sub-interfaces)
- **Measurement POD**: ComdareMeasurementSnapshotV1 (v1, layout-stable)
- **Workload POD**: WorkloadConfig, WorkloadOp (deterministic across all permutations)

Any breaking change to these contracts requires a major-version bump.
