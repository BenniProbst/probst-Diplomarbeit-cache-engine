# comdare-build-tools

## Modul-Scope

Das **comdare-build-tools**-Modul kapselt die **CODEGEN + VALIDIERUNG + CMAKE-INFRASTRUKTUR** der Cache-Engine:

### Drei Säulen

#### 1. **is_original_validator** (apps/is_original_validator)
- Automatische Discovery von Legacy-Code-Function-Bodies durch Regex + Brace-Balancer
- SHA256-Validierung gegen Lock-File (erkennt Modifikationen)
- Generiert ist_original_<fn>() constexpr-Bools + PaperManifest-Struct + OriginalCodeMixin-Alias
- **Verwendung:** `comdare_generate_is_original_mixin()` (cmake/is_original_codegen.cmake)

#### 2. **anatomy_codegen_tool** (apps/anatomy_codegen_tool)
- Enumeriert 11 bekannte Compositions oder externe (Plugin-)Compositions
- Generiert CMake-Snippet mit `comdare_codegen_anatomy_module_list()`
- Basis für Permutations-Raum-Aufzählung (V41.F.6.1.R5.F)

#### 3. **adhoc_emitter** (apps/adhoc_emitter)
- Auto-Emitter für Permutations-.cpp-Module (1-wise- oder Pilot-Überdeckung)
- 2-Pass-Build: Configure-Time Emission → Build-Phase Kompilierung
- **Status V41.P2 (2026-05-31):** Diagnostischer Pilot, **NICHT** autoritative F15-Quelle
  - F15-Messungen verwenden statt dessen named-Composition-Organe via `comdare_codegen_anatomy_module_list`

## Migrations-Hinweis (Doku 25)

Zukünftige Integration über **DependencyManager** (Folgephase):

```cmake
# Monolith-Konsumption (Heute)
add_subdirectory(${CMAKE_CURRENT_SOURCE_DIR}/external/comdare-cache-engine)
target_link_libraries(my_target PRIVATE comdare::cache_engine_builder)

# Module-Konsumption (Folgephase: DM-Integration)
find_package(comdare-build-tools REQUIRED)
target_link_libraries(my_target PRIVATE comdare::build-tools)
```

Dieses Modul ist **header-only** (keine Runtime-Dependencies) und bleibt bei Monolith-Konsumption vollständig kompatibel.

## Verwendungsbeispiele

### 1. is_original_validator — Legacy-Code-Validierung

```cmake
comdare_register_paper_wrapper(
    PAPER_ID a04_mimalloc
    EXT_DIR "${CMAKE_SOURCE_DIR}/ext/allocator/A04-mimalloc"
    EXT_SENTINEL_FILE src/alloc.c
    LEGACY_DIR "${CMAKE_SOURCE_DIR}/libs/cache_engine/legacy_code/paper_a04_mimalloc"
    FILES src/alloc.c src/alloc-aligned.c
    OUTPUT_HEADER "${CMAKE_BINARY_DIR}/generated/a04_mimalloc_is_original.hpp"
    NAMESPACE "comdare::cache_engine::allocator::axis_06_allocator::generated::a04_mimalloc"
    WRAPPER_NAME mimalloc
)
```

Generiert Header mit:
```cpp
inline constexpr bool kIsOriginal_allocate = true;
inline constexpr bool kIsOriginal_deallocate = true;
// ... OriginalCodeMixin-Template
```

### 2. anatomy_codegen — Compositions-Snippet-Emission

```cmake
comdare_codegen_anatomy_module(
    TARGET_NAME anatomy_perm_art_shared
    COMPOSITION_TYPE "::comdare::cache_engine::compositions::ArtComposition"
    COMPOSITION_HEADER "compositions/art_reference.hpp"
    LIBRARY_TYPE SHARED
    OUTPUT_DIR "${CMAKE_BINARY_DIR}/generated_anatomy_modules"
    FINGERPRINT "art_pilot"
)
```

### 3. adhoc_emitter — Permutations-Auto-Skalierung

```cmake
comdare_run_adhoc_emitter(
    OUTPUT_DIR "${CMAKE_BINARY_DIR}/generated_adhoc"
    STATUS_OUT _emitter_status
    FULL_COVERAGE  # 1-wise statt Pilot
)

if(_emitter_status STREQUAL "FOUND")
    comdare_build_adhoc_modules(
        OUTPUT_DIR "${CMAKE_BINARY_DIR}/generated_adhoc"
        PILOT_PREFIX comdare_adhoc_pilot
        AXIS_GEN_DIRS ${COMDARE_ALL_AXIS_GENERATED_DIRS}
    )
endif()
```
