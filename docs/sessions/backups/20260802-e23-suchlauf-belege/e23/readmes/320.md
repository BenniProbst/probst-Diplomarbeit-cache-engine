# comdare-pmc

Generische PMC-Quellen-Familie (Performance Monitoring Counter) der comdare-measurement-Familie,
Baseline-Stufe `comdare-baseline_1-instrumentation` (Quellen/Instrumentation).

**Inhalt:** `IPmcSource`/`PmcCounters`-Interface + `NullPmcSource` (ehrlicher Null-Fallback),
`LinuxPerfPmcSource` (perf_event_open, Linux-only, selbst-guarded),
`WindowsPcmPmcSource` (Intel PCM, selbst-guarded), compile-time Factory.
