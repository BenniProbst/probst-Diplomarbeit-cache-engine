## (b) ARCHITEKTUR-/SCOPE-ENTSCHEIDUNGEN (mit Begründung)

1. **A1: CEB-Default O3 statt O2, NICHTS global gepinnt.** Begründung (User): Ledger OF-2 verbietet globales Festsetzen, „alle Teile sind beweglich". O3 ist IEEE-754-deterministisch (≠ Ofast, das den 1-Thread-Mess-Determinismus bricht). Der eigentliche Verstoß saß nicht im Default-Startwert, sondern im **O2-Byte-Anker in `system_axes_version_suffix()`** (nur Abweichungen von O2 bekamen ein `+opt=`-Sidecar) → entfernt, Provenienz wird **immer** emittiert.
2. **A2-Ist-Architektur (verifiziert):** 3 Schichten — `profile_facade/` oben; `builder/` + `measurement/` als Peers. `build_orchestrator` ist achsen-blind (kein Verstoß). Reale Befunde: `perm_runner` fehlplatziert in `builder/experiment_tree/`; Bau+Messung tief im builder verheiratet; **echter Verstoß = Verzeichnis-Zyklus `builder↔measurement`** über `pmc_source.hpp` (measurement inkludiert aufwärts).
3. **A2-Hybrid-Kriterium:** nicht „Leaf-Enum vs CRTP", sondern **Fehler-KLASSIFIKATION (Builder zieht geteiltes Taxonomie-Vokabular hoch) vs Bau-KONFIGURATION (Builder empfängt Wert von Facade/Planer)**. → (2) Facade rechnet `supports_fno_gnu_unique` aus dem Achsen-Typ, reicht runter; (1) Builder hebt `BuildResult` auf `std::expected<…, CompilerCompilerErrorClass>`.
4. **System- vs Mess- vs Organ-Achsen (Code-Wahrheit, korrigierte E1-Formulierung):** `AxisKind{organ, system_measurement, system_config}`. `binary_id` = **ausschließlich** Organ-Komposition über `kCompositionAxisNames` (18 Slots). `opt_level`/`simd` sind `system_config` → **vergrößern die golden-Fixture NICHT**, sondern multiplizieren nur die **Mess-Matrix** (CSV-Zeilen, unterschieden über Spalte `build_version`). ⇒ „golden + Messwerte löschen" schrumpfte real auf 2–3 überholte Mess-CSVs; das binary_id-Manifest wird höchstens regeneriert.
5. **Ebenen-Doktrin Haupt→Unter→Option (V35-Tabelle §2.1, autoritativ):** `compiler` = Haupt-Achse (Family gcc/clang) → `opt_level` = Unter-Achse → `{O0,O1,O2,O3,Ofast}` = **Optionen**. Analog `extension_hardware` → `simd` → `{no_extension,avx2,avx512}`. Ziel-XML: `<system_axes><compiler><opt_level><option value="O2"/></opt_level></compiler><extension_hardware><simd><option .../></simd></extension_hardware></system_axes>`.
6. **Freigabe-Prinzip (Owner-KERN, als Memory verankert):** System-Achsen **geben Ressourcen frei** (Existenz testbarer HW-Eigenschaften), Organ-Achsen **setzen durch**; Organ-Nutzung ≤ System-Freigabe. 7. **INC-1: gemeinsames Dach** `topics::Axis` über Mess+System+**Organ**; Organ-Achsen definieren zusätzlich die **Gattungen** (welche Gattung welche Organ-Achsen braucht).
