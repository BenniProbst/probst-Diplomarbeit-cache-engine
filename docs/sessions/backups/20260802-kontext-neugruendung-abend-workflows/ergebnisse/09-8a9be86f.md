### B-3 — Das verbindliche Architektur-Modell (aus D-7 abgeleitet, in Doc 21 §A verankert)
- **B+-Baum, Layer-sortiert**: jede Achse = ein Layer; statische Achse = strikter Layer, darunter dynamische Achsen-Nodes bis zur nächsten statischen Konfiguration; Spread einer Node = Variationen EINER Achse (statische Algorithmen ODER dynamische Werte, nie beides).
- **Wurzel = System-Achsen == Meta-Achsen** (inkl. telemetry + Mess-System); Visitor reicht Workloads durch, Strategy im Visitor benchmarkt.
- **Prozess-Dimension** (bauen/messen/auswerten/Hybrid) = **Builder über State-Pattern**.
- **Decorator über das Visitor-Objekt** loggt beim rekursiven Durchgang den State der Tier-Binary-Wahl (Stack).
- **EIN Concept für alle Achsen**: Unter-Achse = Voll-Achse unter der compile-time-Haupt-Achse.
- **Maximale Utilization**: jedes Achsen-Interface muss über alle Nicht-System-Achsen echt angewandt sein, sonst honest-0/no-op; bestehende Algorithmen sind anzupassen.
