## §2 V17.1 Template-Substitution-Mechanismus

`CodegenEngine::generate_module_from_profile` checkt Template-Existenz:

```cpp
auto template_path = opts_.comdare_root /
    "cache_engine/builder/codegen/templates" /
    (profile.id + "_body.hpp.template");
bool has_template = std::filesystem::exists(template_path);
```

Bei `has_template=true`:
- Generated `.cpp` enthaelt `#include "<absolute-template-path>"`
- ABI-Glue verwendet `TemplateBody = ::comdare::cache_engine::builder::generated::ProfileModuleBody`
- create/destroy/run_workload/pull_live_counters delegieren an Template-Body

Bei `has_template=false`: Skelett-Body wie bisher (V9.3-Verhalten).

**Nicht-disruptiv:** bestehender Code funktioniert weiter, neue
Templates werden nur dann genutzt, wenn sie vorhanden sind.
