## §2 V18-Designentscheidung

**Architektur-Konsistenz:** PRT-ART ist Pruefling-Code und gehoert nach
prt-art-Repo (User-Direktive 2026-05-13/14, vergl. V8.2 + V9.4 + V10.1).
V17.1 sucht aktuell nur in `cache_engine/builder/codegen/templates/`.
V18.1 erweitert die Suche um einen zweiten Pfad in der prt-art-Submodule.

### V18.1 Multi-Path-Lookup-Strategie
```cpp
// 1. cache-engine SOTA-Templates (V17.1)
auto sota_template = opts_.comdare_root /
    "cache_engine/builder/codegen/templates" /
    (profile.id + "_body.hpp.template");

// 2. prt-art Pruefling-Templates (V18.1)
auto prt_art_template = opts_.prt_art_root /
    "prt_art/codegen/templates" /
    (profile.id + "_body.hpp.template");

bool has_template = std::filesystem::exists(sota_template);
auto template_path = sota_template;
if (!has_template && std::filesystem::exists(prt_art_template)) {
    has_template = true;
    template_path = prt_art_template;
}
```

`ExperimentDriverOptions::prt_art_root` ist optional (Default: leer).

### V18.2 prt-art Template
Pfad: `prt_art/codegen/templates/prtart_body.hpp.template`
