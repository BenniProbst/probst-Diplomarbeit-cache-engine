## §4 V14.3 CI-Workaround

Statt `gtest_discover_tests` direkt ctest add_test:
```cmake
add_test(NAME ${name} COMMAND ${name})
```

Das umgeht den MSB3073-Fehler bei MSVC + funktioniert in CI.

CI-YAMLs (cache-engine + prt-art + Diplomarbeit) bekommen einen
zusaetzlichen Job: `direct-test-execution` der die test-binaries
direkt aufruft (nicht ueber `ctest`).
