## §2 V26-Designentscheidung

**V25 hat die SOTA-Algorithmus-Profile auf 30/30 expected_workload-Tags
gebracht. V26 zieht den Allokator-Bereich nach.** Allokatoren sind die
horizontale Achse (vs. Algorithmen vertikal) im Permutations-Raum:

```
                    YCSB_A   YCSB_B   YCSB_C   YCSB_D   YCSB_E   YCSB_F
hoard               x        x        x        x        x        x
mimalloc            x        x        x        x        x        x
jemalloc            x        x        x        x        x        x
tcmalloc            x        x        x        x        x        x
...
```

Pro Allokator wird ein Profile-XML angelegt mit:
- `id`, `family_ref` (A01..A20)
- `metadata` (Autoren, Lizenz, Quelle)
- `axes`: typische Verwendung (page-allocator-style, NUMA, SIMD)
- `expected_workload`: Default-Workload-Affinitaet
- `binding`: ABI-Schnittstelle (C `malloc`/`free` vs. C++ `operator new`)
