## §2 V12.1 + V12.2 — Vollstaendige std-Container-Methoden hinzugefuegt

### §2.1 Vector-API (PrtArtSearchEngine<Value>) — 5 neue Methoden
- `assign(InputIt first, InputIt last)` — Range-assign-Template
- `operator[](size_type)` — non-throwing Random-Access (vs at returnt optional)
- `rbegin/rend/crbegin/crend` — Reverse-Iteratoren (read-only, std::vector-konform)
- `emplace_back(Args&&...)` — variadic perfect-forwarding mit density-update
- `swap(other)` — Member-Swap mit `std::scoped_lock` (deadlock-vermeidend)

### §2.2 Map-API (PrtArtSearchEngine<Key, V1, V2...>) — 8 neue Methoden
- `insert_or_assign(k, v)` — std::map-konform, semantisch identisch zu set
- `emplace(k, Args&&...)` — variadic perfect-forwarding-emplace
- `try_emplace(k, Args&&...)` — fail-if-exists Variante
- `operator[](k) const` — Lazy-Read als `std::optional` (Concurrency-safe; KEINE reference)
- `max_size()` — std::map-konform
- `rbegin/rend/crbegin/crend` — Reverse-Iteratoren (read-only)
- `swap(other)` — Member-Swap inkl. Counter-Swap (inserts_/erases_/hits_/misses_)
- `key_comp() / value_comp()` — Comparator-Accessoren

### §2.3 Bewusst NICHT implementiert (Concurrency- oder PRT-ART-spezifisch)
- `merge` / `extract` (std::map) — wuerden cross-engine-Locks benoetigen
- `operator[](k)` als reference (lazy-insert) — Concurrency-unsicher
- mutable `begin/end` non-const-Iterator — Concurrency-unsicher

## §3 V12.3 — search_engine ABI Container-Vertraege

```cpp
// search_engine.hpp ergaenzt um:
[[nodiscard]] virtual bool contains(key_t const& k) {
    return this->lookup(k).has_value();   // Default: lookup-basiert
}
[[nodiscard]] virtual std::size_t count(key_t const& k) {
    return this->contains(k) ? 1u : 0u;   // Default: 0/1
}
[[nodiscard]] virtual std::optional<value_t> find(key_t const& k) {
    return this->lookup(k);               // Default: identisch lookup
}
[[nodiscard]] virtual bool clear() { return false; }  // Default NotImplemented
```

Adapter-Subklassen ueberschreiben optimal (contains/count/find via direkte
Engine-API statt zweimal lookup).
