## §2 Designentscheidungen (autonom)

### V10.1 Loeschungs-Strategie
- `git rm -rf prt_art/legacy_reimpl/P*/` — die 14 Subordner
- `prt_art/legacy_reimpl/README.md` bleibt als Migrations-Marker mit Hinweis "MIGRATED to prt-art"
- `prt_art/legacy_reimpl/CMakeLists.txt` bleibt minimal (no-op + message)

### V10.2 resolve_baustein operationalisieren
- Concept aus V8 hat `has_baustein` + `resolve_baustein` Concept-Skelett
- V10.2: konkretisiere mit Tag-Resolver-Pattern
- `resolve_baustein<PrueflingTag, BausteineAxis>` returnt zur Compile-Time
  entweder Pruefling-Variant oder SOTA-Variant als std::variant_alternative_t

### V10.3 notify_*-Methoden Implementation
- `notify_density_threshold(pct)` → impl_->components_.density_tracker.update(pct)
- `notify_hot_path_detected(path)` → impl_->components_.path_prefetch.note(path)
- `notify_workload_change(locality)` → impl_->components_.hypothesis_metrics.adapt(locality)

### V10.5 ExperimentDriver Phase 2 Auto-Pickup
- ExperimentDriver liest XmlConfigParser-Output (V8.6 hat sota_profiles)
- Wenn `cfg.sota_profiles.size() > 0`: pro Profil generate_module_from_profile aufrufen
- Fingerprint = Hash(profile.id) deterministisch

### V10.6 Messreihen-XML Konfiguration
- ExperimentDriverOptions.messreihen_mode = MessreihenMode::Defined / Full
- ExperimentDriverOptions.sota_profile_filter = optional<vector<string>>
- messung_driver liest spec → setzt opts → ruft run_pipeline_full

### V10.4 Codegen-Tests
- `tests/unit/test_codegen_from_profile.cpp` mit 3 Cases:
  - Generate ART-Profil → File existiert + enthaelt korrekte Tags
  - Generate Multiple Profiles → eindeutige Fingerprints
  - Generate ohne id (Fehlerpfad) → kein Crash
